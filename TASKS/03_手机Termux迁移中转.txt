【7】环境事实 / 已知坑
------------------------------------------------------------------------
- 手机厂商（小米/华为/OPPO/vivo）后台杀进程很狠，
  必须同时做「电池无限制 + 允许自启动 + termux-wake-lock + Termux:Boot」，否则会莫名掉线
- 手机重启靠 Termux:Boot 自恢复；网络波动会换隧道 URL，
  所以第 11 步的自动更新（Vercel API + Deploy Hook）是必需品，不是可选项
- 手机是住宅/蜂窝 IP，对成人站比 VPS 友好得多（Vercel 是数据中心 IP 才被封）
- 用 Vercel API 改 env 需要一个 VERCEL_TOKEN（建议最小权限、可随时吊销）；
  用 Deploy Hook 触发重部署则不需要 token
- cloudflared quick tunnel 出的是 HTTP 隧道，不支持 CONNECT 当代理用，
  所以沿用任务01 的「取回 API」设计（GET /<secret>/fetch?u=...），不要改成正向代理
- iOS 不可行（不给长时间后台），只考虑安卓
- Cloudflare 固定域名隧道需 NS 迁移，已排除（见【5】决策1）
- serveo / bore 已排除（见【5】决策2、3）
